# 🥭 Mango R!pe
YOLO-based mango ripeness detection web app built with Streamlit

## ⚙️ Installation & Run

### 1. Clone Repository

```
git clone https://github.com/vlauuua/mango-ripe.git
cd mango-ripe
```

### 2. Install Dependencies

```
pip install -r requirements.txt
```

### 3. Run Application

```
streamlit run app.py
```
